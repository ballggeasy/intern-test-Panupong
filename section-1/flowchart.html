Flowchart ระบบจัดการสิทธิ์การเข้าถึงข้อมูลโครงการ (Project Access Control)

2 Role: Admin / Employee · ใช้ Mock Data · แสดงแนวคิด RBAC

Admin Employee RBAC / การตรวจสอบสิทธิ์ ปฏิเสธ / Error 
flowchart TD
  S([เริ่มต้นระบบ]) --> L[แสดงหน้า Login]
  L --> U[ผู้ใช้กรอก Username]
  U --> API[จำลองเรียก API ตรวจสอบข้อมูลผู้ใช้
จาก Mock Data]
  API --> D1{Login สำเร็จ?}
  D1 -- ไม่สำเร็จ --> F[แสดงข้อความ
เข้าสู่ระบบไม่สำเร็จ]
  F --> L
  D1 -- สำเร็จ --> SS[บันทึก Session
userId และ Role]
  SS --> R{RBAC: ตรวจสอบ Role
เป็น Admin หรือ Employee?}

  R -- Admin --> GA
  R -- Employee --> GE

  %% ---------- Admin ----------
  GA{RBAC Guard /admin
Role === Admin?}
  GA -- ใช่ --> AP[เข้าสู่หน้า Admin /admin]
  AP --> A1[ดู Task ทั้งหมดในระบบ]
  A1 --> A2[สร้าง Project ใหม่]
  A2 --> A3[สร้าง Task ใหม่]
  A3 --> A4[มอบหมาย Task ให้ Employee คนใดก็ได้
assigned_to = Employee ID]
  A4 --> A5[แก้ไขสถานะ Task ของทุกคนได้]
  A5 --> AX[Admin พยายามเข้า /employee]
  AX --> GE

  %% ---------- Employee ----------
  GE{RBAC Guard /employee
Role === Employee?}
  GE -- ใช่ --> EP[เข้าสู่หน้า Employee /employee]
  EP --> E1[ระบบกรอง Task
assigned_to === userId]
  E1 --> E2[แสดงเฉพาะ Task ที่ได้รับมอบหมาย]
  E2 --> E3[Employee เลือก Task เพื่อเปลี่ยนสถานะ]
  E3 --> D3{Task.assigned_to
=== CurrentUser.id?}
  D3 -- ใช่ --> E4[เปลี่ยนสถานะ To Do เป็น Done]
  D3 -- ไม่ใช่ --> E5[ปฏิเสธ: ไม่สามารถเข้าถึงหรือแก้ไข
Task ของ Employee คนอื่น]
  E5 --> E2
  E4 --> EX[Employee พยายามเข้า /admin]
  EX --> GA

  %% ---------- Unauthorized ----------
  GA -- ไม่ใช่ Admin --> UA[ปฏิเสธการเข้าถึง
Unauthorized]
  UA --> RE[Redirect ไป /employee]
  RE --> EP
  GE -- ไม่ใช่ Employee --> UE[ปฏิเสธการเข้าถึง
Unauthorized]
  UE --> RA[Redirect ไป /admin]
  RA --> AP

  %% ---------- Logout ----------
  A5 --> LO
  E4 --> LO
  LO{ผู้ใช้กด Logout?}
  LO -- ไม่ใช่ ทำงานต่อ --> R
  LO -- ใช่ --> CL[ล้างข้อมูล Session/Login]
  CL --> RL[กลับไปหน้า Login]
  RL --> Q{ใช้งานต่อ?}
  Q -- ใช่ --> L
  Q -- ไม่ --> E([จบการทำงาน])

  class F,UA,UE,E5 deny;
